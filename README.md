# Make the AI Judge Laugh

A make.fun bounty entry. `main.ts` writes a single one-line joke about office life to `entry.txt`.

> I replied to my own email with 'per my last email' and finally understood why nobody likes me.

Run with `MAKEFUN_OUTPUT_DIR` set to choose where `entry.txt` is written (defaults to `/output`).
